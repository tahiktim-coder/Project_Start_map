6SHIP DECKS · ENDINGS

DECK MODALS (any time)

  • BRIDGE — scans, warp cost (damaged: +50%)
  • LAB — deep scan
  • QUARTERS — crew manifest; REST −1 R stress −1
  • CARGO — use items; revival items bring back the dead (tagged)
  • ENGINEERING — probes; jump cost ×2 if damaged
  • FABRICATION — buy upgrades S
  • REPAIR any deck S (−30% with engineer alive)

ENDINGS

  • Structure → ENTER: Promised Land (4+ crew, calm) / Transcendence / Last Gift
  • OBSERVE: The Record
  • SETTLE NEARBY: New Earth (3+ crew) / Quiet End
  • SACRIFICE: Synthesis (A.U.R.A. cooperative) / Consumption
  • Wrong Place: accepted
  • Colony: viability (type, temp, gravity, air) → 95 / 80 / 60 / 30 / 0% + sector + DATA 🎲 → ~30 text branches
secret ending "The Answer" (8/8 logs) is never called

GAME OVER

  • All crew dead
  • Hull breach: 3+ decks down, can't afford repair
  • Commander breakdown
  • Stranded: no energy, no way to get any
  • A.U.R.A. mutiny (3rd vent)

WHAT A RUN FEELS LIKE TODAY

Length6 sectors, ~3–5 stops each. Only energy gates progress.
DecisionsWhich planet to spend energy on; when to risk crew on EVA; when to jump; where to colonise.
WinColonise anywhere (dice + planet quality) or reach the Structure.
SaveAutosave after warp, jump, EVA. One slot, localStorage.
Not in gameThe Pursuer tutorial system comms portrait screen — exist in docs / unused files only.

WEAKEST UI MOMENTS (my read)

1Planet warp has no visual — the biggest, most repeated action is a log line and a 1 s pause.
2Sector transition, campfire, briefing, start menu, game-over each use their own hardcoded colours (blue, neon green, black) — five different looks.
3Narrative modal is a long scroll: header cut off at top, choices below the fold (your screenshot).
4Orbit view: planet overlaps the environment readout at narrower widths; command deck is a plain button list.
5Costs and risks hide in small grey text; outcomes only appear in the log, not on the thing you clicked.
